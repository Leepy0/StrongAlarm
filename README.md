# StrongAlarm (강력한 알람)

걸어야 꺼지는 알람. Android(갤럭시 폴드) + Wear OS(갤럭시 워치) + SmartThings 조명.

- 알람 해제: **걸음 30보** (워치·폰 중 큰 값)
- 휴무 판정: 캘린더 일정 제목 키워드 + 공휴일 캘린더 + 주말, 특근은 자동 울림
- 판정이 틀렸을 때: 알람 화면의 **휴무 버튼 5초** (누르는 동안 소리·진동 일시정지)
- 조명: 알람 15분 전부터 디밍 → 5분 미해제 시 스위치 점등 → 해제 5분 뒤 자동 소등

상세 스펙과 결정 사항은 [docs/SPEC.md](docs/SPEC.md).

## 상태

v0.1 초기 구현. **아직 실기기 빌드·실행 검증 전**이다.
`core` 모듈(휴무 판정·스케줄 계산)은 단위 테스트 27개 통과, `app`/`wear`는 Android Studio에서 첫 빌드 시 컴파일 오류가 있을 수 있다.

## 구조

```
core/  순수 Kotlin 로직 + 단위 테스트
app/   폰 앱 (Kotlin, Jetpack Compose, minSdk 34)
wear/  워치 앱 (minSdk 33)
```

## 빌드 & 설치

1. Android Studio로 열기 (Gradle 8.14.3, AGP 8.11.1, Kotlin 2.2.0 — 최신 버전 업그레이드 제안이 뜨면 적용해도 됨)
2. **폰 앱과 워치 앱은 같은 PC에서 빌드**해야 한다. 서명(debug 키)과 applicationId가 같아야 폰↔워치 메시지가 전달됨
3. 설치
   ```bash
   ./gradlew :app:installDebug                 # 폰 (USB 또는 무선 디버깅)
   adb connect <워치IP>:<포트>                  # 워치: 설정 > 개발자 옵션 > 무선 디버깅
   ./gradlew :wear:installDebug
   ```
4. 단위 테스트: `./gradlew :core:test`

## 초기 설정

### 폰
1. 앱 실행 → **권한** 카드의 항목 모두 허용
   - 알림, 캘린더, 신체 활동, 전체 화면 알림, 배터리 최적화 제외, 정확한 알람
   - (선택) 다른 앱 위에 표시: 화면이 켜져 있을 때도 알림 대신 알람 화면이 바로 뜸
2. 삼성 설정 > 배터리 > 앱 절전: 이 앱을 **제한 없음**으로
3. 방해 금지 모드 사용 시 예외에 **알람** 허용 확인
4. **공휴일 캘린더**: Google 캘린더에서 "대한민국의 휴일" 구독 + 동기화 켜기 → 앱이 처음 캘린더 권한을 받을 때 자동 선택. 안 되면 휴무 판정 카드에서 직접 선택
5. 휴무 판정 카드에서 키워드와 판정 대상 캘린더(공유 캘린더 배제용) 확인
6. 테스트 카드의 **10초 뒤 테스트 알람**으로 화면 끈 상태 동작 확인

### 워치
1. 워치에서 앱 실행 → 권한 허용(알림, 신체 활동), 배터리 최적화 제외
2. 폰 테스트 알람 시 워치 진동·걸음 전송 확인

### SmartThings (조명, 선택)
SmartThings 개인 토큰(PAT)은 24시간 만료라 OAuth 앱을 만들어 사용한다.

```bash
npm install -g @smartthings/cli
smartthings apps:create
#  - 앱 종류: OAuth-In App
#  - Scopes: r:devices:*  x:devices:*
#  - Redirect URI: https://httpbin.org/get   (앱 WebView가 가로채므로 실제 접속되지 않음)
#  → 출력된 Client ID / Client Secret 보관
```

앱의 조명 카드 → Client ID·Secret·Redirect URI 입력 후 저장 → 로그인 → 기기 불러오기 → 디밍 조명·스위치 선택 → 조명 테스트.

토큰은 Android Keystore로 암호화해 저장하고, 매일 알람 사용으로 자동 갱신된다(30일 가까이 미사용 시 재로그인 필요).

## 사용

- **알람 시각**: 단일 시각
- **일회성 변경**: 특정 날짜만 다른 시각에 울림 (휴무 판정 무시)
- **23시 안내 알림**: 내일 울림 여부와 사유. [시각 변경], 스킵일 때 [그래도 울리기]
- **이력**: 판정·울림·해제·조명 동작 기록
